Questions

Where are my files stored?

In your browser and on the machine running the backend. iLikePdf has no cloud storage and no telemetry.

Do I need an account?

No. Accounts and tokens are only enabled when you deploy the optional Cloudflare Worker.

How do payments work?

Checkout runs through Stripe (cards) and PayPal. Tokens are credited by the payment provider's webhook or capture callback, not by the browser.

Can I self-host the whole stack?

Yes. The Java backend and React front end run on any machine with JDK 25 and Node.js. The Worker is only needed for shared accounts.
